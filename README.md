# Portfolio - Sávio Ramon Lima Nogueira

Portfolio profissional desenvolvido com Next.js, TypeScript, Tailwind CSS e Framer Motion.

## Tecnologias

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Como rodar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000` no navegador.

## Build de produção

```bash
npm run build
npm run start
```

## Manutenção de conteúdo

Os textos, links, especialidades, projetos, experiência e formação ficam em `data/portfolio.ts`.

O botão de currículo usa o arquivo:

```txt
public/curriculo.pdf
```
